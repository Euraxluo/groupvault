# GroupVault · Jobs 式手机信息架构与视觉重设计

**日期:** 2026-10-26（Asia/Shanghai）  
**状态:** 待用户审阅规格后写实现计划  
**范围:** 前端 UX / IA / 文案 / 视觉；不改链上合约语义

## 1. 产品承诺（3 秒）

**付费进群聊天，成熟了就一键变成 DAO。**

设备：手机竖屏优先（约 390×844）。语言：界面中文优先。

Convert 之后仍以**聊天为主**；金库与投票不占底栏。升级成功后**先带去金库看一眼**，再回聊天。

## 2. 设计原则（Jobs）

1. **一条故事** — 发现/建群 → 付费进群 → 聊天 → 升级为 DAO → 金库一眼 → 回聊天。
2. **一屏一个主动作** — 次要信息进 sheet / 二次确认。
3. **对人说人话** — `1 NEAR`，不写 yocto；「升级为 DAO」代替 Convert / factory / Sputnik（详情小字可注明）。
4. **藏协议** — 技术自夸、Demo Story、长免责条退出主路径。
5. **拇指区** — 主 CTA 够大；确认从底部升起。

## 3. 导航

底栏三格：

| Tab | 作用 |
| --- | --- |
| **消息** | 会话列表（进群 = 全屏聊天） |
| **发现** | 付费进群 |
| **我的** | 钱包、网络、关于 |

**砍掉：** 独立 Groups / DAO / Inbox 底栏；首页 Demo Story 说明书；独立 DAO hub 首页作为默认落点。

进群后：顶栏左群名，右 **「群」** 按钮 → 群概况 sheet。

## 4. 视觉

- 浅色底、近黑字；主按钮近黑；成功/已连接用极少量系统绿。
- **砍掉**大紫块英雄卡、四宫格营销卡堆砌。
- 列表优先于卡片墙；圆角与间距统一；底栏线性图标，选中近黑/加粗。
- 品牌紫若保留，仅作极小点缀（默认方案：不用主色紫）。

## 5. 文案规则

- 入群费、升级费用：人类可读 NEAR。
- 空态一句产品承诺 + 主按钮。
- 链上公开聊天提示：首次进聊天一行可关闭，不做黄条长警告。
- 错误/成功各一句；不堆栈。

## 6. 关键屏（Must）

1. **消息** — 列表；空态：「付费进群聊天，成熟了就一键变成 DAO」+「发现群」/「新建群」。
2. **新建群** — 名、入群费、可选简介 →「创建」→ 直达该群聊天。
3. **发现** — 群卡（名、费、人数）→ 确认支付 → 聊天。
4. **群聊天** — 气泡 + 输入；顶栏「群」。
5. **群概况 sheet** — 成员、入群费、状态；未升级且群主：主 CTA「升级为 DAO」；已升级：主 CTA「金库与投票」。
6. **升级确认 sheet** — 约 X NEAR、成员变初始理事会、一句风险 →「确认升级」。
7. **升级成功** — 轻庆祝 → **强制进入金库一眼**（余额/空态）→ 主按钮「回到聊天」；聊天顶栏小「DAO」标记。
8. **金库与投票（二级）** — 余额、转账提案、投票列表；从概况或升级成功进入。质押为次级，不挡主路径。
9. **我的** — 地址、余额、testnet、断开。

**Won’t（本轮）：** DKG 仪式入口、Inbox 底栏、Demo Story 轨、桌面宽屏优先布局。

## 7. 信息架构示意

```
消息 ──► 群聊天 ──► 群概况 sheet ──► 升级确认 ──► 金库一眼 ──► 回聊天
  │                      └── 金库与投票（已 DAO）
发现 ──► 支付确认 ──► 群聊天
我的
新建群 ──► 群聊天
```

## 8. 验收（手机）

- 评委不读说明书也能走完：建群 → 第二人入群 → 聊天 → 升级 → 见金库 → 回聊天。
- 主路径无 yocto、无 Demo Story、无独立 DAO 底栏。
- 一屏一帧可截（390×844）；主 CTA 拇指可达。
- 与现有链上流程兼容（create / join / chat / convert / treasury proposal）；仅 UX 壳重做。
